01Programme Overview

What This Programme Covers

Most Malaysian factories track OEE. Very few use it correctly. Numbers are reported, meetings are held, and production losses continue — because the measurement system and the loss structure are never properly built into daily operations. This program changes that. Participants learn to design a real OEE measurement system for their lines, calculate all three components correctly, classify losses using the Six Big Losses framework, and build shop-floor accountability structures that sustain improvement over time.

02Programme Content

Programme Modules

M1

Module 1: OEE Fundamentals

  • What OEE actually measures — and what it doesn't
  • The three components: Availability, Performance, Quality
  • World-class OEE benchmarks by industry (semiconductor, automotive, FMCG)
  • Why most factory OEE numbers are wrong
M2

Module 2: Six Big Losses Framework

  • Equipment failure losses
  • Setup and adjustment losses
  • Idling and minor stoppage losses
  • Reduced speed losses
  • Quality defects and rework losses
  • Startup and yield losses
M3

Module 3: Measurement System Design

  • Designing data collection for your line
  • Manual vs automated data capture tradeoffs
  • Defining planned production time correctly
  • Building the loss classification system operators will actually use
M4

Module 4: Loss Analysis and Prioritisation

  • Pareto analysis of your Six Big Losses
  • Linking losses to root causes (5-Why, Fishbone)
  • FMEA integration for chronic losses
  • Quick wins vs long-term improvement roadmap
M5

Module 5: Shop-Floor OEE Culture

  • Daily management board setup
  • Shift handover using OEE data
  • Operator involvement in loss recording
  • Management review cadence and escalation
M6

Module 6: Action Planning Workshop

  • Participants build a 30-day OEE improvement plan for their own line
  • Loss elimination targets and ownership matrix
  • Measurement system design document
