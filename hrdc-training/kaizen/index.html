01Programme Overview

What This Programme Covers

Running Kaizen events is easy. Making Kaizen stick is hard. Most Malaysian factories have tried Kaizen — they've held events, filled out forms, and generated improvement ideas that quietly faded away three months later. This program addresses the system failure, not just the tools. Participants learn to run structured Kaizen events using the Certified Process Kaizen Engineer methodology, build the management routines that sustain gains, and develop shop-floor improvement habits that don't rely on periodic events to survive.

02Programme Content

Programme Modules

M1

Module 1: Kaizen Philosophy

  • The real meaning of Kaizen — what it is and is not
  • Kaizen vs Kaikaku (continuous improvement vs breakthrough improvement)
  • Why events without culture always revert
  • The management system that Kaizen requires
M2

Module 2: Waste Identification (Muda, Mura, Muri)

  • 7 Wastes: definitions, examples, factory walkthrough
  • Overburden (Muri) and unevenness (Mura) — often overlooked
  • Waste observation on the Gemba (factory floor)
  • Video-based waste identification exercises
M3

Module 3: Kaizen Event Methodology

  • 5-day Kaizen event structure (condensed format for training)
  • PDCA as the operational backbone
  • Team composition and facilitation
  • Rapid improvement tools: 5S, standard work, visual management
M4

Module 4: Gemba-Based Problem Solving

  • Go to the Gemba — observe before analysing
  • 5-Why root cause analysis in practice
  • A3 thinking for improvement documentation
  • Countermeasure design and verification
M5

Module 5: Sustaining Gains

  • Standard work as the improvement baseline
  • Visual management to make problems visible
  • Leader standard work and daily Gemba walks
  • Kaizen governance: steering, review, recognition
M6

Module 6: Kaizen Workshop

  • Teams run a structured mini-Kaizen on a real production area
  • Improvement ideas prioritised using effort/impact matrix
  • 30-day implementation plan created per team
