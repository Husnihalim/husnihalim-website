Work Photo Collection

Created: 2026-05-01

This folder contains the first organized pass of work-related image candidates found from the local WhatsApp cache.

Source used:
- WhatsApp local media and message database on this Mac.

Selection rule:
- Last three years from 2023-05-01 through 2026-05-01.
- Images attached to chats or captions matching work/training/consulting keywords such as kaizen, training, trainer, consult, factory, kilang, FMM, MABES, OEE, Lean, VSM, 5S, VAC, JSSB, PRITECH, Inokom, Kiswire, and similar company/project terms.

What is included:
- 548 copied image candidates, grouped into company or project folders.
- manifest.csv, which maps every copied file back to WhatsApp date, chat name, caption, and original local source path.
- _contact_sheets, with quick visual review sheets for each folder.

Notes:
- The original WhatsApp files were not moved or changed.
- Some screenshots, posters, and document images are intentionally kept in this first pass because they came from relevant work chats. Use the contact sheets to quickly trim anything not needed.
- Google Photos was visible in Chrome, but its visual page surface was blank during this run. No Google Photos files were downloaded to avoid selecting the wrong items.
- macOS blocked direct structured Calendar database access. Calendar app search was used for visible date context, but no full calendar export was produced in this pass.
