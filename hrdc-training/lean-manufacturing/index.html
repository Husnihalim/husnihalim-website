01Programme Overview

What This Programme Covers

Lean is not a cost-cutting programme — it is a system for making value flow without interruption. Malaysian factories that implement Lean tools without understanding the system behind them get islands of improvement that don't connect. This program builds genuine Lean capability: participants understand the principles first, then learn the tools that serve those principles. Value Stream Mapping is used throughout as the primary diagnostic framework — giving teams a shared language for seeing waste and planning the future state.

02Programme Content

Programme Modules

M1

Module 1: Lean Principles

  • Value from the customer's perspective
  • The value stream — all steps from raw material to customer
  • Flow, pull, and the pursuit of perfection
  • Lean vs efficiency — why they are not the same thing
M2

Module 2: Waste Identification

  • 7 Wastes (Muda) with factory-floor examples
  • Mura (unevenness) and Muri (overburden)
  • Value-added vs non-value-added vs necessary non-value-added
  • Waste walk: live observation exercise
M3

Module 3: Value Stream Mapping (VSM)

  • Current state map: how to draw and read one
  • VSM data box metrics: CT, C/O, uptime, shifts
  • Identifying the bottleneck and constraint points
  • Future state design principles
M4

Module 4: Flow and Pull Systems

  • One-piece flow vs batch-and-queue
  • Takt time calculation and production levelling
  • Kanban system design principles
  • FIFO lanes and supermarket design
M5

Module 5: Lean Tools in Practice

  • 5S as the foundation of visual flow
  • Standard work: takt, sequence, WIP
  • Quick changeover (SMED) basics
  • Error-proofing (Poka-Yoke) overview
M6

Module 6: Future State Planning

  • Teams build a future state VSM for their own production area
  • Kaizen burst identification and prioritisation
  • Implementation roadmap with 30/60/90-day milestones
